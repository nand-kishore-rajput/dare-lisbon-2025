## Lecturers and Topics

| Lecturer                    | Title                                                             | Description                                                                                                      |
| :-------------------------- | :---------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------- |
| **Nuno Preguiça**           | *The Quest for “Optimal” Conflict Resolution*                     | Focuses on techniques for resolving update conflicts in geo-replicated and local-first systems using CRDTs.      |
| **Ragnar Mogk**             | *Protocol RDTs: Programs as Replicated Data*                      | Introduces the idea of replicating entire programs, not just data, to ensure correctness under weak consistency.   |
| **Guido Salvaneschi**       | *Taming the Distributed Systems Beast with Programming Languages* | Explains how programming-language abstractions and behavioral types simplify distributed application design.     |
| **José Orlando Pereira**    | *Highly Available Analytical Processing*                          | Demonstrates analytical processing over eventually consistent data using Conflict-Free Replicated Data Views.    |
| **Carlos Baquero**          | *Efficient Synchronization of Sets and CRDTs*                     | Presents methods for decomposing state and using set reconciliation to minimize replication overhead.            |
| **Alexey Gotsman**          | *Database Isolation Levels*                                       | Clarifies formal definitions of transaction isolation levels such as serializability and snapshot isolation.     |
| **Tom Van Cutsem**          | *Introduction to Blockchain and Distributed Ledgers*              | Provides an overview of blockchain foundations, consensus mechanisms (PoW, PoS, BFT), and smart-contract models. |
| **Burcu Kulahcioglu Özkan** | *Testing Distributed System Implementations*                      | Discusses systematic testing and fault-injection strategies for distributed and concurrent systems.              |
| **Kevin De Porre**          | *Automated Verification of Replicated Data Types with VeriFx*     | Explains how the VeriFx language leverages SMT solving (Z3) for automated verification of CRDT correctness.      |
| **Annette Bieniusa**        | *Advanced CRDT Programming Models*                                | Explores design patterns, programming models, and formal reasoning techniques for replicated data structures.    |
